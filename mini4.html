歩容を考える

ここでは歩行のパターンやそのアルゴリズムのことを歩容と呼んでいる。

歩くうえで最も重要な動作は、いくつかの脚が地面を蹴っている間に他の脚を進むうえで動かしやすい位置に移動することである。 これは前に進む場合であれば蹴り切った脚を前へ振り出す動作である。 この振り出す動作で重要なのは、十分に早いことと地面への接触を避けることである。

ロボットで歩行を実現する場合、地面への接触を避けるために脚に関節をつける方法が一般的である。 しかし今回は小型化のために関節を省くので工夫する必要がある。

まず今回作成するロボットのモデルを定義しておく。

右手系のXYZ空間において

  • Z==0を地面とする
  • +Z方向を上とする
  • +X方向を前とする
  • 0＜X＜1 && 0＜Y＜0.7(だいたい) && Z=1 の長方形を胴体とする
  • 脚
    • 胴体の各頂点から-Z方向に長さ1
    • 胴体と接する端を通るY軸と平行な直線を軸として回転
      • +Yに進む右ねじの回転方向が正

直進

次のような周期関数を用意する。

これをGLSL風にC言語で記述すると

float fract(float x){return x-floor(x);}
float clamp(float x,float a,float b){return fmin(fmax(x,a),b);}
float saturate(float x){return clamp(x,0.,1.);}
float mix(float x,float y,float a){return x*(1.-a)+y*a;}
float step(float a,float x){return x<a?0.:1.;}
float linearstep(float a,float b,float x){return saturate((x-a)/(b-a));}

float walk(float t){t=fract(t)*2.;return saturate(mix(mix(3.,-2.,linearstep(0.,.9,t)),linearstep(.9,2.,t),step(.9,t)))*2.-1.;}// [-1~1]

地面と水平な長方形の4本ある脚(LF,RF,LB,RB)のうち対角に位置する2本ずつをペアとして考える。 片方のペアが地面に垂直に接地している状態でもう片方のペアが接地していない状況を考える。 脚の重さが0かつ重心が脚の対角線の交点上に存在すると仮定すればこのロボットは直立した状態を維持することができる。

進行方向側を負とした脚の振り出す角度に、先ほどの関数が時刻を渡したときに返す値を代入する場合を考える。 2つのペアで位相を半分ずらした状態であれば、これは2つのペアが交互に進行方向に振り出す動作である。

// 雰囲気こんな感じ
// V=速度
LF.rot=V*walk(t);
RB.rot=V*walk(t);
RF.rot=V*walk(t+0.5)
LB.rot=V*walk(t+0.5);

回転角の絶対値は地面からの距離に比例しているので、先のグラフで傾斜が緩やかな区間は地面に接触している。 2つのペアが交互に接地して振り出す脚は一瞬接地するものの接地を避けることができている。

実際に試し、前進することを確認した。 速度を負にすることで後退も可能である。

旋回と合成

旋回を実現するには右の脚と左の脚が異なる推力を生み出す必要がある。 先ほどの速度Vを左右で独立させた状態を考える。

// 雰囲気こんな感じ
// VL=左速度 VR=右速度
LF.rot=VL*walk(t);
RB.rot=VR*walk(t);
RF.rot=VR*walk(t+0.5)
LB.rot=VL*walk(t+0.5);

わかりやすい例としてVL=-1,VR=1を考える。 その場で左旋回すれば成功である。 ペアの脚の回転角の絶対値は等しいので、脚が接地する区間は直進の場合と同様と考えられる。 接地しているときの各ペアの上から見た接地点の動きについて、LF_RBペアは右回転しながら遠ざかる動き、RF_LBペアは右回転しながら遠ざかる動きである。 ペアの脚に等しく荷重がかかっている場合、回転以外の成分は打ち消しあって結果として回転成分のみ残る。 胴体に対して地面が右回転なので、地面に対して胴体は左回転すると考えられる。

実際に試し、左旋回することを確認した。 VL,VRを操作して右回転や直進との合成も可能である。
